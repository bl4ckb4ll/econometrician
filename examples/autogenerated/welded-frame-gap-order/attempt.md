# Qualitative orders on a projected square gap

Two gap orders can constrain one unknown blade slope when the tool, calibration, placement, projection and assembly episode agree. A registered pair supplies exact projected lengths and source station identities. The function from that pair to a one-sided strict slope bound is pure. The main library operation conditions one nominated source on named observations, returning an exact feasible range with a witness, a contradiction attributed to both limiting readings, or no admitted bounds. Unregistered readings, visibility, indistinguishability and different sources keep their original records and a reason. Duplicate evidence has a single contribution. Different records claiming one immutable evidence identity are rejected.

The runnable fixture needs the retained Idriç compiler, the Chez host path and the exact interval library. The source model assumes a straight reference blade, common-side projection, a known correspondence at the two stations, and the length unit fixed by the named projection. Physical inference beyond those assumptions remains outside this slice.

## Use the checked module

`Frame.GapOrder.constrain_signed_blade_slope` accepts a `BladeSlopeSource` and a finite list of `GapObservation` values evaluated under one candidate frame shape. The caller supplies stable source IDs and consistent exact coordinates for each referenced station within that candidate. The projection identity binds the common comparison basis and length unit. Register a pair only when both features are identified in the same common-side view. Supply `unregistered` when that premise is missing. Remounting, changing the view or tool, or observing a different assembly episode requires the corresponding new identity.

The output `conditioned` retains admitted bounds and deferred readings. A `feasible_range` describes exactly the admitted bounds, and its rational witness belongs to that interval. Deferred evidence requires its own interpretation. If the admitted bounds contradict, `excluded_by` carries the two limiting readings and each exact threshold. `no_admitted_bounds` is an unresolved result. A repeat of the same evidence identity and content counts once. Conflicting content under a single identity stops conditioning.

For a positive projected station step, the exact threshold is lateral change divided by that step. The strict bound is above the threshold when the first gap is larger and below it when the second gap is larger. Two distinct station samples at the same or reversed longitudinal coordinate are deferred. Visibility and indistinguishability alone supply no slope bound. A physical diagnosis requires a justified connection from the modelled features to the physical member.

## Execution

The fixture ran on x86-64 Debian 13. The Idriç compiler was built from `isomorphisms/Idric@2bce7677f513d711875e978bd6f5ad28b9e54d58` with Chez Scheme 10.4.1. The interval library came from `dilapidated-shed/intervals.idr@b3574ac06101f53a97c10839b420e656bd93bf46`. Its `intervals-idric.ipkg` and all included checks built and ran successfully.

Build the interval library with the pinned `idris2 --build intervals-idric.ipkg` and run `interval-idric-tests`. Use the compiler's installed/built package prefix and built Chez executable for the application compilation. Set `IDRIS2_PATH` to the interval checkout's `build/ttc`, then build `frame-gap-order.ipkg` in the Econometrician checkout with `idris2 --build frame-gap-order.ipkg`. Append that build's `build/ttc` to `IDRIS2_PATH` for the fixture. From the Econometrician checkout, compile `examples/autogenerated/welded-frame-gap-order/Main.idric` with `idris2 --source-dir examples/autogenerated/welded-frame-gap-order --cg chez examples/autogenerated/welded-frame-gap-order/Main.idric -o frame-gap-order`, then run the emitted `frame-gap-order`.

Ten assertions passed. The synthetic station steps first use 2 and 3. The reference leaning thresholds coincide at 3/2, leaving an empty intersection. The bowed thresholds leave the open interval (−2/3, 3/2). A separate fractional step of 3/2 with lateral change −1/4 produces the expected strict lower bound −1/6. The fixture checks duplicate idempotence, retained contradiction attribution independent of reading order, remount refusal, unresolved observations and altered-content evidence rejection.

Four independently built modifications each exited 1 under the same fixture. Closing the strict endpoints failed the first sighting check. Ignoring later bounds failed the straight-profile exclusion. Equating remounts failed the source-scope check. Silently discarding conflicting content failed the evidence identity check. This receipt covers checked Idriç and host Chez on the named pins.

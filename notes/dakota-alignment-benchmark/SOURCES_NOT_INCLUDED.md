# Source-evidence boundary

This public repository package intentionally does not duplicate the raw personal photographs, screenshots, and other binary source artifacts recovered from the ChatGPT file library during the audit.

Their identities, provenance classifications, and relationships to the benchmark are retained in `data/source_manifest.csv` and the three partitioned `data/evidence_ledger_*.csv` files. The private audit package also retains `data/raw_evidence.jsonl`.

This omission is a publication/privacy boundary, not a claim that the derived records replace the originals. Any conclusion requiring visual reinspection must return to the original artifact.

The prior public caster sensitivity experiment is already archived at `../dakota-caster-recheck/` in this repository and is referenced rather than duplicated.
